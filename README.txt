Frost Sky Islands
A free 3D model kit from Shuriken Studio
https://shuriken.studio/kits/frost-sky-islands

A free low-poly frost sky islands kit for Roblox Studio: a matching set of floating islands in several sizes for a frozen sky world, a winter lobby or a sky obby. The hero island, about 100 studs across, carries an ice fortress with crystal spires, snowy pines and a frozen waterfall spilling over the edge. Two medium islands hold a snowy cabin beside a frozen pond and a cracked frozen lake with a wooden jetty, a smaller island bristles with glowing ice crystals around a frost shrine, and three small islets are sized for jumping between. Every island has a walkable top at player scale and a craggy rock underside hung with icicles, and the set shares one look so it reads as a single world. They're built with extra detail as showpieces, and free to use in your own games.

Using them
  Roblox Studio: Import 3D, choose a GLB, insert.
  Blender: File > Import > glTF 2.0.
  Unity, Godot, Unreal, three.js: import directly or through glTF.
